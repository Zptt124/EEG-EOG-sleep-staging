D 按协议规则自己重写了选块代码（没有调用 C 的 `make_plan`），用同一份冻结特征和第一周 trainer 重跑了全部 580 次拟合，再用自己的重抽样代码计算区间。

固定尝试口径下，D 的区间与 C 完全相同：两边的重抽样算法和随机数调用顺序一致。严格口径下端点相差不超过 0.01 pp：D 在两种口径之间连续使用同一个随机数生成器，C 每次重新设置种子。

## 4. 判读（τ = 1 pp，代理窗口）

- Ying 的 EDF 起点代理窗口下，ΔB−ΔA = +0.03 [−0.44, +0.45]，整个区间落在 ±1 pp 以内，四折中三折为正、一折为负，幅度都很小。
- 方向和量级与 Sleep-EDF 关灯网格的结果一致：线性头为 −0.21 [−0.60, +0.15]，BiGRU 为 −0.01 [−0.63, +0.62]。在两个队列上，**单独加入分期边界筛选，对"新人 − 混合随机"的影响都在实践带以内。**
- 适用范围：Ying 只是代理窗口（记录起点 ≠ 已核实的关灯时间），只用了前两晚和 29 份名单；冻结特征来自在 Sleep-EDF 上训练的 W4 30k。
- Ying 的 ΔA = +0.68 [−0.17, +1.54]：在记录起点网格下，新人相对混合随机的平均优势为正，区间跨 0。
