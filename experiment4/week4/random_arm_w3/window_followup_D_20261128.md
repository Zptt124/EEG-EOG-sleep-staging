# D｜窗口追问：共同 26 份名单上的逐阶段 F1、跨窗口配对区间、扩跑精度估计（2026-11-28）

这份分析只用已经归档的混淆计数：C 的三组，加上 D 的随机组。没有重新拟合，评估者是 16 位开发评估者，head seed 0。

重抽样方法与 C 相同：名单有放回、名单内抽块有放回、评估者在两个 8 人队列内加权，两个窗口共用同一套重抽样，共 10,000 次。

脚本 `05_window_followup.py`，日志 58，输出在 `analysis_window_followup/`。

## 1. 跨窗口配对差（主口径：每组固定尝试 600 段；单位 pp）

| 比较 | 旧窗口 | 关灯窗口 | 关灯 − 旧（配对） | 缩小的名单数 |
| --- | ---: | ---: | ---: | ---: |
| 新人 − 原人原夜 | +1.64 [+0.51, +2.80] | +0.55 [−0.66, +1.78] | **−1.10 [−2.11, −0.12]** | 20/26 |
| 新人 − 随机 | +1.67 [+0.67, +2.81] | +0.36 [−0.50, +1.24] | **−1.32 [−2.34, −0.38]** | 20/26 |

- 第一行与 C 报告的 −1.10 [−2.10, −0.12] 一致，说明这份脚本和 C 的统计口径对齐了。
- **"新人相对随机的优势在关灯窗口下变小了"这件事本身是确定的**：区间不含 0，26 份名单里有 20 份变小。
- 严格等预算口径（关灯窗口里两组都拿到 600 个标签），方向相同：
  - 新人 − 原人原夜：−1.51 [−2.96, −0.12]，23 份名单；
  - 新人 − 随机：−1.62 [−3.04, −0.30]，23 份名单。
- 共同 26 份名单上，旧窗口的"新人 − 随机"是 +1.67，比 30 份名单时的 +1.48 还大。所以衰减不是"4 份名单退出"造成的。

## 2. 变小，是"新人变差"还是"别的组变好"？

各组的 Macro-F1 水平（%，26 份名单 × 5 次抽块的平均）：

| 窗口 | 原人原夜 | 原人另一夜 | 新人新夜 | 随机 |
| --- | ---: | ---: | ---: | ---: |
| 旧窗口 | 60.10 | 60.74 | **61.74** | 60.07 |
| 关灯窗口 | 60.79 | 61.20 | **61.34** | 60.98 |
| 变化 | +0.69 | +0.46 | −0.40 | +0.91 |

**新人组本身基本没变（−0.4），差距缩小主要是因为原人原夜组和随机组在关灯窗口下变好了（+0.7、+0.9）。**

一种可能的解释（未验证）：旧窗口参照分期裁掉了头尾，从同一个人的夜里能挑的块有限。关灯窗口覆盖关灯后 9 小时，同一个人、同一夜可选的片段更多样，"不换人"的两组因此受益。这需要 C 统计的睡眠期构成来核对。

## 3. 逐阶段 F1：差别主要出在哪一期

"新人 − 随机"的逐阶段 F1 差（pp）：

| 阶段 | 旧窗口 | 关灯窗口 | 关灯 − 旧 |
| --- | ---: | ---: | ---: |
| W | +0.60 [−0.22, +1.50] | −0.07 [−0.84, +0.67] | −0.67 [−1.68, +0.25] |
| N1 | +0.86 [−1.37, +3.12] | +0.20 [−2.06, +2.58] | −0.66 [−3.30, +1.93] |
| N2 | +1.34 [+0.35, +2.54] | +0.50 [−0.34, +1.48] | −0.84 [−1.81, +0.05] |
| N3 | +2.96 [+0.22, +6.35] | +1.41 [−0.82, +4.11] | −1.55 [−4.32, +1.06] |
| REM | +2.61 [+0.05, +5.56] | −0.26 [−2.40, +1.73] | **−2.87 [−5.76, −0.17]** |

"新人 − 原人原夜"的变化方向相同：N3 −1.83，REM −1.54，N1 −1.46，但区间都跨 0。完整表见 `per_stage_contrasts.csv`。

- 旧窗口里，新人相对随机的优势主要在 **N2、N3、REM**。
- 到关灯窗口，**REM 的优势消失得最明显**，这是唯一一个区间不含 0 的阶段。N3 和 N2 也变小了，但区间跨 0。
- 注意：
  1. 这里一共看了 10 个逐阶段比较，REM 那一个刚好不含 0，有可能是多重比较带来的偶然结果。
  2. 按 C 的提醒，这只是机制线索，不能据此断定 REM 就是原因。要结合 C 的睡眠期构成表来看：如果新人组在关灯窗口里拿到的 REM 相对变少，这条线索才算成立。

## 4. 扩跑值不值：抽块从 5 次增加到 20 次

把关灯窗口"新人 − 随机"的不确定性拆开来看：

| 来源 | 方差（pp²） |
| --- | ---: |
| 全部（当前，5 次抽块） | 0.199 |
| 其中：仅评估者 | 0.016 |
| 其中：仅名单内抽块 | 0.044 |
| 名单之间（真实差异） | 名单均值方差扣掉抽块部分后，每份名单 1.53 |

每份名单抽块次数增加后，预计的 95% 区间（假设均值仍是 +0.36）：

| 抽块次数 | 保守估计 | 乐观估计 |
| ---: | --- | --- |
| 5（现在） | [−0.52, +1.23] | 同左 |
| 10 | [−0.47, +1.18] | [−0.42, +1.13] |
| 20 | [−0.44, +1.15] | [−0.36, +1.07] |
| 50 | [−0.43, +1.14] | [−0.32, +1.03] |

**结论：不值得扩跑。** 主要的不确定性来自"名单和名单之间本来就不一样"，不是每份名单里抽块抽得少。抽块加到 20 次，区间半宽也只能从 0.88 缩到 0.72–0.80，上限仍然超过 +1 pp。到时候既不能说新人更好，也不能说两者等效，结论不会改变。

要真正收窄区间，得**增加名单数**（更多不同的 5 人起点），或者换一个更大的训练池或数据集。在只有 46 人的 Sleep-EDF 训练池里，名单之间已经有大量个体重叠，继续加名单的收益也有限。

## 5. 可以交给全组的结论

1. 换成关灯窗口后，"新人"相对"原人原夜"和"随机"的优势都**确定地变小了**，约 1.1–1.3 pp。这不是名单退出造成的。
2. 变小的主要原因，是不换人的两组在关灯窗口下变好了，新人组本身基本没变。
3. 逐阶段看，旧窗口的优势集中在 N2、N3、REM；关灯窗口下 REM 的优势消失得最明显。这只是线索，需要 C 的睡眠期构成表来核对。
4. 在现有设计下继续增加抽块次数，不会改变"关灯窗口下分不出新人和随机谁更好"的结论，不建议扩跑。
