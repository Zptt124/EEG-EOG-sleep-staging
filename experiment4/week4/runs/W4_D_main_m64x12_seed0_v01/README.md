## 目前能说什么、不能说什么

- **val MSE 还在下降**：30k 之前每次 val 都创了新低，还没有出现拐点，所以停止规则也不会在 30k 停（规则本来就规定 30k 之前不停）。降幅在变小：5k→10k 降了 0.0048，25k→30k 只降了 0.0005。
- **EEG 和 EOG 同步下降**：训练 loss 的平均值，EEG 从 0.078（0–5k）降到 0.060（15k–30k），EOG 从 0.098 降到 0.077。val MSE 也是两个模态一起降，没有看到一个降、另一个升的"拔河"现象。EOG 的 MSE 始终比 EEG 高一些。
- **不能说的**：
  - 这些数字只说明去噪目标在 held-out 上越来越好，**不代表下游分期更好**；下游 probe 还没做。
  - 只有 1 个 backbone seed。
  - 30k 和后面的步数谁更好，要等主实验跑完、做完各点 probe 才能判断。
- **速度**：s/step 中位数约 0.49（最大 0.56），没有出现变慢的警告；显存峰值 5,978 MiB。
