# 成员 D → 成员 C：实验一锁定选块包 v01 与精度估算（2026-11-28）

## 一、锁定的选块包

基于成员 C 交接的 `handoff.json`。7 个文件的 SHA-256 已逐一核对，全部一致；`handoff.json` 本身的 SHA-256 记录在 `lock.json` 中。

由脚本 `04_lock_selection.py` 生成，脚本的 SHA-256 也记在 `lock.json`。**全程没有读取任何新增片段的分期标签。**

| 文件 | 内容 |
| --- | --- |
| `lock.json` | 种子、随机数规则、名单、条件、主策略、主分析单元数（780）、输入与输出文件的 SHA-256 |
| `priorities.csv` | 每份名单 × 每次重复 × 每个唯一块的两套优先级：`priority_cpool`（k=0，只用于构造 C 池）、`priority_select`（k=1，A/B/C 与各策略共用） |
| `c_pools.csv` | 每份名单 × 每次重复的条件 C 保留池（逐格列出） |
| `selections.csv` | A/B/C × 策略的入选块。`primary=1` 是主分析的新人与混合随机；deepen、other_night 只在其可行子集内给出，供附表 |
| `random_source_composition.csv` | 混合随机组每次的来源构成（原夜、另一夜、新人块数）和覆盖人数、夜数 |
| `feasibility.csv` | 逐条件、逐名单、逐重复、逐策略的可行标记 |
| `epochs_needed.csv` | 全部入选块用到的 epoch 及其在既有缓存中的来源（shared / supplement / missing） |
| `spotcheck_units.csv` | 预先指定的 6 个跨机抽查单元及块清单的散列 |
| `precision_estimate.csv` | 精度估算表（见第二部分） |

**随机数规则**：每份名单、每次重复，把该名单的唯一块按 `block_id`（记录号:起始 epoch）字符串稳定排序后，用 `numpy.random.default_rng([2026112903, 名单, 重复, k]).random(n)` 生成优先级，数值小者优先，平分按 `block_id`。numpy 版本为 1.26.4。

**已通过的核对**（脚本内置，任何一项不通过都会报错退出）：
- 每份名单 30 格；混合随机的时段配额等于新人组各时段的格数，也和 `mixed_quotas.csv` 一致；
- 所有候选块和 1,200 段起点都不重叠；
- 每格的 C 保留数 = `n_C_to_keep` = B 容量；
- 每个条件 × 名单 × 重复 × 策略恰好 10 个不同的块；
- 逐名单可行性与 `roster_feasibility.csv` 完全一致：新人 26、混合随机 26、原夜 14、另一夜 24、四组 13；
- 主分析单元数 26 × 5 × 3 × 2 = 780。

**要补的特征**：入选块共用到 71,160 个 epoch，其中 64,570 个在共享缓存里，6,131 个在既有补提里，**459 个缺失，需要补提**（见 `epochs_needed.csv`，`cache_source = missing`）。

## 二、精度估算（正态近似，未看任何新得分）

依据：关灯窗口现有"新人 − 混合随机"的标准误约 0.445 pp（26 份 × 5 次）。历史跨窗口设计反推出的条件间相关约 0.50。新设计中 A 与 B 有约 89% 的块相同，相关预计更高，真实值在正式运行后报告。

| 条件间相关 ρ | ΔB−ΔA 区间半宽 | 最小可检测差（80% 功效） | 检出 0.5 pp | 检出 1.0 pp |
| ---: | ---: | ---: | ---: | ---: |
| 0.50（历史） | 0.87 | 1.25 | 20% | 61% |
| 0.70 | 0.68 | 0.97 | 31% | 83% |
| 0.80 | 0.55 | 0.79 | 43% | 94% |
| 0.90 | 0.39 | 0.56 | 71% | 100% |

- **建议实践阈值 τ = 1 个百分点**，与最小可检测差分开登记。ρ ≥ 0.8 时能可靠检出 1 pp，"区间落入 ±1 pp"这种等效结论也有机会得出。
- **需要全组事先知道的预期**：在关灯网格上，B 只去掉约 10% 的候选块（1,290 → 1,154 个唯一块），10 块里平均只换掉约 1 块。所以 ΔB−ΔA 很可能远小于旧窗口到关灯窗口的 1.32 pp 衰减，最可能的结果是落在实践带以内。这个结果本身也有信息量：它说明原来的衰减主要来自网格、窗口长度或时段边界，而不是睡眠边界筛选本身。

## 三、跨机抽查清单（预先指定）

名单 1、第 1 次重复，A/B/C × 新人/混合随机，共 6 个单元。块清单和散列见 `spotcheck_units.csv`。

等成员 C 锁定补提后的缓存，D 用同版缓存、相同种子和训练配置重训这 6 个单元，按片段编号对齐逐段预测。

验收线：每个单元逐段预测一致率 ≥ 99.9%。同时记录不一致段数、Macro-F1 差和两台机器的环境。主结果始终取成员 C 的正式运行。
