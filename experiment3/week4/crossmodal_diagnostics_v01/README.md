# W4 C · 跨模态诊断的按人复算

基于 A 已发布的 20,000 个窗、46 名预训练受试者，核对无重复目标窗、配对覆盖完整、受试者均来自预训练训练池。C 对 A 预先定义的低频 MSC 指标按受试者汇总，保留同窗和错时配对，用 10,000 次受试者 bootstrap 计算区间。每个受试者等权。

同窗−错时的低频 MSC 平均差为 0.0341，95% 区间 [0.0310, 0.0373]，46/46 人方向为正。

按 A 的总体 EOG RMS 上四分位阈值划分高振幅窗和其余窗，每人分别计算 MSC 配对差，再对两层取差。高振幅层额外差为 0.0318，95% 区间 [0.0251, 0.0386]。

这些结果支持信号同步性与低频耦合有关。A 的 Welch 配方只有 5 秒窗内少量子窗，高 MSC 绝对值受估计方法影响。眼动伪迹和真实生理耦合均可能产生同步差异，需结合三组 EOG-only 下游结果判读。

尚待 A 同窗 30k 和 B 错时 30k 的预测、匹配的无 EEG 30k probe，以及三组统一复评。当前诊断不足以确定跨模态预训练收益。
