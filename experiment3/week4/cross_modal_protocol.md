# W4 实验 C · 跨模态三组对照

第 1 天交接给 A（实现同窗条件）、B（运行错时对照和统一复评）、D（公共训练接口与无条件对照）。

## 三组怎么做

| 组别 | EOG 去噪目标 | 训练时的 EEG 条件 | 负责人 |
| --- | --- | --- | --- |
| 同窗 EEG | 当前 5 秒 EOG 窗 | 同一记录中起止时间完全一致的 Fpz-Cz 窗 | A |
| 错时 EEG | 同一批 EOG 窗 | 同一记录中相隔 60–300 秒的 Fpz-Cz 窗，完整落在记录内 | B |
| 无 EEG | 同一批 EOG 窗 | 始终为空，复用 D 主线 30k checkpoint | D |

- 共用 B 锁定的 8 人预训练 held-out 名单、训练池及窗清单、12 层 / hidden 64 小 EEGDM、backbone seed、30k 步和 EMA 取权重规则。保留 EEG 去噪样本及原模态 ID，只有 EOG 去噪分支接收额外 EEG 条件。三组尽量复用目标窗、打乱顺序和扩散噪声/t 的随机流。记录训练配置、窗清单及 checkpoint 哈希。D 若已锁定训练窗，A/B 按 D 的窗清单做条件配对和覆盖检查。
- 错时时间以窗口起点之差计算。对每个目标窗，从同记录、完整有效、满足绝对间隔 60–300 秒的候选中，用固定种子均匀抽一个，记录目标窗 ID、条件窗 ID 和有符号间隔。保留两种方向及边界的实际分布。条件配对使用时间戳和窗有效性，睡眠标签不参与。预先检查覆盖率。没有候选的目标窗在 A/B 两组都置空并登记数量，保留三组同一批去噪目标。
- A/B 使用同一个 EEG 条件编码器和同一个逐窗 dropout 设置，建议固定 `p=0.2`。条件采样、dropout 与扩散噪声使用各自独立的随机流。D 的接口允许 `condition_eeg=None`，并支持批内逐窗有效掩码。同窗、错时及置空共用相同前向入口。缺失条件与 dropout 走同一空条件分支。保留 D 的原 backbone 和 modality ID 入口。
- A/B/D 下游全部走 EOG-only 且 EEG 条件为空。提取脚本验收时，用有无 EEG 文件的两种输入环境核对 EOG 特征及预测一致。三组统一 EOG 信号预处理、特征层、t、池化和线性探针配方。建议沿用 W3 的 std、t=1，取小主干全部 12 层。若配方有调整，三组一起锁定后再评分。

## 评估与交付

- 预训练验证按 B 的固定窗、噪声和 t，用 EMA 权重按每 5 步一段、EEG/EOG 分开报 MSE。三组先统一评估空条件，比较与下游一致的推理方式。若另做带条件 MSE，单列条件状态和配对方式。
- 下游主指标为 **N1 AP 和 Macro-F1**。建议 5 人预算为主、14 人为补充，使用既有预算名单和一致的 head seed（先跑 0，有余量三组同时补 1/2）。沿用预算内按人 5-fold CV 选 epoch、全名单重训、8 人 dev 最终评分。N1 另报原始 F1、训练侧 OOF 选 α 后的 F1、α 值及调整后的 Macro-F1。5 折如遇某一受试者缺类，选轮和 α 使用拼接后的 OOF 预测计算。封存测试集不参与。
- B 先核对三组 11 列预测逐行对齐 epoch ID、受试者、记录、时间和真值，汇总三组绝对分数，再报同窗−无 EEG、错时−无 EEG、同窗−错时三个配对差及按 dev 受试者成对重采样的 95% 区间。多个 head seed 使用同批受试者，另报逐 seed 差值。A 给 B/C 的材料包括 30k 权重、EOG-only 预测表、相关性和 coherence 图。B 第 6 天上午给 C/D 三组汇总，C 下午给 D 判读。

## 怎样判读

| 结果 | 解释与后续判断 |
| --- | --- |
| 同窗较无 EEG 提高 N1 AP，Macro-F1 也提高 | 支持同窗条件改善 EOG-only 表征。建议在独立 backbone seed 上复验，报告配对区间及逐 seed 方向。 |
| N1 AP 提高，Macro-F1 下降 | 有 N1 排序收益和整体分期代价，保留为候选，并报告代价大小及区间。只有 α 调整后 N1 F1 上升时，证据指向判定门槛。 |
| 同窗和错时均优于无 EEG，二者相近 | 观察结果与同夜上下文或额外条件分支的作用相容。三组设计无法单独分离这两种解释。 |
| 同窗优于错时 | 支持收益依赖时间对齐。真实同步生理信息和 EOG 伪迹都可能解释。只有当同窗同时优于无 EEG 时，才有证据支持它带来下游收益。 |
| 区间跨零、方向不稳或仅 val MSE 改善 | 记为初步信号或生成目标改善，优先用同预算独立 backbone seed 检验方向，再决定是否延长训练。 |

A 的诊断图按受试者或记录汇总，比较同窗与同夜错时的 Fpz-Cz/EOG 相关性和低频 magnitude-squared coherence。建议预先固定 0.3–4 Hz 诊断频带，并把 Welch 窗长、频率分辨率和有效样本量记入图注。如能用相同协议分层，另查看高 EOG 振幅窗与其余窗的差异。结合这两类图判断眼动伪迹线索；同步相关和低频 coherence 本身仍与真实生理耦合相容。

交接采用的具体默认值是 60–300 秒错时窗、0.2 dropout、5 人档为主、0.3–4 Hz 诊断频带。A/B/D 在首轮运行前统一写入配置，登记实际值。
