## 当前判读

三head seed汇总中，N1 AP的所有配对区间均跨零。5人档同窗−无EEG的Macro-F1为−0.63 [−1.11,−0.07] 个百分点，区间不含零且方向为下降；14人档为+0.29 [−0.25,+0.85]，区间跨零。因此应将旧的“Macro-F1区间均跨零”概括限定到C的单head seed表，不能用于新的三seed汇总。

N1 F1在5人和14人档方向不同，同窗与错时的差也尚未明确。当前证据未确认稳定跨模态收益。5人档的下降来自单个backbone seed，尚不足以推断跨模态方法普遍有害。建议将长训资源优先用于已建立收益的预训练主线；跨模态追加预算时先检验一个独立backbone seed的30k三组复验。

同窗−错时的差反映对时间对齐的依赖，真实同步生理信息与眼动伪迹均可能解释。C 对 A 的46人/20,000窗诊断复算中，同窗−错时的低频 MSC 差为0.0341 [0.0310,0.0373]，高EOG振幅层额外差0.0318 [0.0251,0.0386]。将该诊断与下游差结合判读，仍无法单独识别伪迹与真实生理耦合。

## 同窗提取前向修正

A 的39号提取脚本将 xc_flag 的零初始化视作训练后仍为零，使用了官方 LatentActivityExtractor。实际30k EMA中的 xc_flag[0] 有256个非零值，最大绝对值0.018858、L2范数0.065360。D的空条件前向会加上该已学习的嵌入，官方提取器会绕过它。

C 在同一模型、同一SC4031记录的8段信号上比较，两种前向所得768维std池化特征全部6144个坐标不同，最大绝对差0.002570、平均绝对差0.000156。权重本身可以复用，本次已改用D的04号正确前向重新提取全部53,496段并重跑探针。去EEG验收与空条件前向一致性分别检查输入依赖和模型计算路径。

该修正与PyTorch/缓存精度变化一起影响相对于A早期表格的数值。本报告统一采用这次重新提取和探针的结果，旧表作为追溯资料。

补充复算与C此前结果接近，当前科学判读保持为“未确认稳定收益”。C和D都已完成统一流程的重提及复评，A现有权重与发布可保留并附实现差异说明；此次交接不要求A重复这些已完成的计算。后续提取统一使用04号脚本。
