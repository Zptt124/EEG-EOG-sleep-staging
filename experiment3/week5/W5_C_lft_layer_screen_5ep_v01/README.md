# W5 C 后三层 LFT 的训练轮数复查

用本机已有的 W4 C 逐秒特征缓存续跑。两组共用 D 的 W3 普通 30k EMA、5 人标签预算、head seed 0、同一训练侧五折和 LFT 配方。把选轮上限从 2 提到 5。全层复用 W4 留存的前五轮 OOF 预测，后三层每折从原第 2 轮检查点继续。两组均从原重训检查点续训到折外结果选定的轮数。核验确认前两轮 OOF 曲线和重训记录完全保留。 [原 2 轮筛查](../W5_C_lft_layer_screen_v01/README.md)

## 开发集 Macro-F1

| 选轮上限 | 全 12 层（实际选轮） | 后 3 层（实际选轮） | 后 3 层减全 12 层［95% 区间］ |
| --- | ---: | ---: | ---: |
| 2 轮 | 67.91%（第 2 轮） | 62.68%（第 2 轮） | −5.23［−10.29，−1.44］个百分点 |
| 5 轮 | 69.16%（第 4 轮） | 67.49%（第 5 轮） | −1.67［−4.94，+1.60］个百分点 |

点估计差距缩小 3.55 个百分点，对差距变化的配对 95% 区间为［−1.18，+8.87］个百分点。两阶段的区间都在同一批 8 名开发受试者上做 1,000 次配对 bootstrap。结果显示原有性能差距随训练长度而变化的线索，5 轮筛查仍不足以确认差距确实缩小或两种读出等效。后三层仍选到了第 5 轮上限。

5 轮上限下，后三层原始 N1 F1 的配对差为 +8.73［+1.84，+15.76］个百分点。N1 AP 差为 +1.12［−5.85，+3.49］个百分点，OOF 判定调整后 N1 F1 点估计为全层 39.52%、后三层 34.72%。目前可报告原始判定下的改善，N1 排序收益仍待确认。

两阶段四份预测已对齐同一批 21,186 条开发集样本。封存测试集未使用。本轮是同一开发集上的单 seed 短程复查。C 的 self-conditioning 四格可以在拿到匹配资产后独立继续。
