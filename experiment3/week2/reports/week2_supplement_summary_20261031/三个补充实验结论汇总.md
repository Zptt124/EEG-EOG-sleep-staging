# 三个补充实验结论汇总

2026-10-31。三项均已结束，新增160个不重复分类头并通过最终审计。取层消融的40个all20参考来自第一个补充实验，不重复计数。最后一项于18:09完成。测试集始终封存。

## 1. 固定训练预算：最差格对停止与选模规则高度敏感

40个头均训练50轮、取最后轮；原有训练前缀和原选中权重精确复现。原最差预定格（10%/适配seed0/分类seed0）的Macro-F1配对差从-1.574变为+0.082个百分点，N1 F1差从-8.756变为+0.223个百分点。该异常退步在改变停止/选模规则后消失。

平均适配效果仍接近零，见下表。这里同时改变了提前停止和检查点选择，不能把全部影响仅归因于早停。固定50轮的绝对成绩低于原最佳验证轮的方案，因此它是诊断控制，不是被证明更优的训练配置。

| 预算 | 指标 | 原早停 S1−S0（百分点） | 固定50轮 S1−S0（百分点） |
| --- | --- | ---: | ---: |
| label10 | macro_f1 | -0.121 | -0.062 |
| label10 | n1_f1 | -0.689 | -0.276 |
| label25 | macro_f1 | +0.026 | -0.033 |
| label25 | n1_f1 | +0.097 | +0.062 |

## 2. 类别加权：N1有一致改善，同时存在精确率与准确率权衡

仅改变五类训练样本数的逆平方根权重，与相同固定50轮的未加权头配对。观察到40/40个加权头的N1 F1均高于对应未加权头；这是本轮模型对的描述，不是40个独立受试者试验。S0与S1都改善，因而不能将该收益归因于主干适配。

| 预算 | 表征 | Macro-F1：未加权→加权 | N1 F1：未加权→加权 | N1 recall：未加权→加权 |
| --- | --- | ---: | ---: | ---: |
| label10 | S0 | 70.622% → 70.694% | 28.662% → 29.954% | 25.337% → 27.907% |
| label10 | S1 | 70.559% → 70.717% | 28.386% → 29.743% | 25.147% → 27.782% |
| label25 | S0 | 72.136% → 72.491% | 36.153% → 39.480% | 36.111% → 46.016% |
| label25 | S1 | 72.103% → 72.549% | 36.215% → 39.437% | 36.294% → 45.785% |

以25% S1均值为例，N1召回36.29%→45.78%，精确率36.86%→35.26%，accuracy77.83%→76.76%。这支持当前损失设定对N1检出的影响，不能直接证明原模型完全忽略N1，也不意味着改善所有类别。

## 3. 取层消融：适配确实改变末层，但没有显现稳定的整体适配收益

三份主干在54名训练者的池化特征中，前18层均与S0逐值完全相同；变化集中在最后两层，相对L2变化约17.3%–19.4%。因此适配不是特征上的空操作，但数值改变不等于更好的分期信息。

原始20层是拼接，不存在层间平均稀释。末5/末2消融只遮蔽EEG，EOG保持all20，名义5120维头和初始化不变；活跃维度减少仍改变有效容量和正则化。

| EEG层组 | 预算 | Macro-F1：S0→S1 | N1 F1：S0→S1 |
| --- | --- | ---: | ---: |
| all20 | label10 | 70.622% → 70.559% | 28.662% → 28.386% |
| all20 | label25 | 72.136% → 72.103% | 36.153% → 36.215% |
| last5 | label10 | 70.987% → 70.826% | 30.104% → 29.670% |
| last5 | label25 | 73.017% → 72.956% | 36.829% → 36.777% |
| last2 | label10 | 69.851% → 69.508% | 27.282% → 27.279% |
| last2 | label25 | 72.925% → 72.754% | 37.332% → 38.123% |

末5层使S0和S1的Macro-F1均值都高于all20，支持取层/有效容量策略值得关注，未体现适配专属收益。六个取层×预算组合中，S1平均Macro-F1都低于匹配S0。末2层在25%预算下出现N1 F1约+0.790个百分点的S1优势，但Macro-F1约-0.171个百分点；10%下没有对应N1优势，不能推广为稳定的整体收益。

## 可以写入汇报的结论

在当前数据划分、8名开发验证者和冻结EOG线性分类设置下，分类头的停止/选模规则可放大个别适配配对差异；训练类频重加权一致改善本轮N1 F1，并伴随精确率/accuracy权衡；选择末5层可改善固定预算下的总体分类均值。主干适配产生了明确的末层数值变化，但上述诊断仍未支持其带来稳定的整体分期收益。

这些补充的均值结果在Macro-F1和N1 F1上尚未超过原早停双模态主比较，不应事后替换原预登记结论。S1先按每主干平均5个分类种子，再平均3个主干；相同8名验证者被重复使用，不能宣称独立测试泛化或未经总体分析的统计显著性。EOG仍为C按D协议在本地重建，未确认与D原文件逐字节一致。

三个补充实验已在本地完成，尚未同步GitHub；本次未启动新的未登记训练。
