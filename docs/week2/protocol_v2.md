- `manifests/split_subjects.csv`是唯一划分：54训练、8开发验证、16最终测试，同人所有夜晚在同一集合。测试封存；8人验证已用于开发，不称独立测试。
- 主名单种子2024，按既有sampling_rank前5/14/27/54人取label10/25/50/100，不重排、不挑人。2025/2026为扩展。

## 预算重建与来源

来源commit、输入/输出SHA、训练夜晚逐记录类别计数见[budget_provenance.json](budget_provenance.json)。生成脚本读取B既有v1的sampling_rank，无随机抽样步骤。默认从已提交的训练记录计数重建：

```bash
python scripts/build_week2_budgets.py --output-dir /tmp/w2-budget-check
python -m unittest discover -s tests -p 'test_week2_budgets.py'
```

Windows将输出路径换成空目录。从A原NPZ复核训练标签计数：

```bash
python -m pip install numpy
python scripts/build_week2_budgets.py --processed <A已核验NPZ目录> --output-dir <空目录>
```

只打开54人训练记录并只取`labels`，不打开验证/测试NPZ。`label_record_counts_v2.csv`是名单统计元数据，不能供C/D无标签训练入口读取。输出同名文件存在时报错；比较三份CSV后由B核验发布。没有利用验证成绩选名单。

## 种子、选模与比较

- 正式下游seed=0,1,2,3,4；名单seed、适配seed、教师seed、下游seed分开记录。seed0可先流程检查，锁定正式配置后补齐，不择优报告。
- 下游按8人验证Macro-F1选最佳权重，早停patience=10；N1/REM在同一权重上报告，不能另挑N1最佳轮。
- C先锁定适配配置和总步数，取固定最后一步或54人内部无标签按人留出规则；不反复按外部8人N1选主干。测试不参与。
- 五个训练seed不是五批新受试者，不能把5×8当40个独立人。种子波动与按人不确定性分开报告；按人配对区间仅作开发集探索，区间含0不证明等效。
- 旧run复用须核对名单、标准化、编码器与特征SHA、头、种子、更新预算、选模及评价样本，登记核验依据。A端到端CNN不是D0；原线性头不能替代B长度1时序头。

## 上下文

25%预算，两表征×长度1/3×seed0–4。固定小投影与一层轻量BiGRU为推荐起点，确切参数先锁定；长度1使用同一头。按subject_id、record_id及原始epoch_index组窗，不跨缺口。可中心段复制填充并记录mask；长度1/3与两表征保持相同中心样本。不能输入邻居真标签。双向上下文仅适合离线分期。

## C输入与权重

原始EMA起点；EEG索引0、200Hz、µV/100、一次staged_mu_law、代理条件14、5秒输入。先不换池化、提取层和监督头。建议末端layers.18/layers.19/out_layer以实际named_parameters和梯度为准，锁定准确参数名；前层与条件嵌入先冻结。

特征提取：t=1、不加输入随机噪声；适配训练：扩散加噪，沿用原始噪声调度和prediction_type，登记优化器与新EMA。核查gate主干梯度及参数更新，禁用冻结推理S4缓存。约100步测速重载起点或计入正式总更新。S1新SHA、新缓存/索引，不覆盖S0，不沿用旧S4缓存；EOG保持S0。主干与下游头明确对应，单先导不能称稳定结论，负结果照交。

## D候选、阈值与追踪

D0真标签监督；D1双模态教师按固定基础置信度接收；D2在同一候选/阈值上仅增加单模态支持/一致性。阈值仅在5/14人内部按人留出校准。先25%再10%，学生结构/初始化/类策略/更新预算匹配，真实更新数、接收量及教师/校准成本另报。两路单模态CNN拼接与A双通道编码器区分。保存候选与拒绝项，无真实未标注标签；质量估计只用内部模拟留出。无CNN对照时结论限于当前EEGDM流程。

## 预测、指标与产物

固定11列，同一行表头：

```csv
sample_id,subject_id,record_id,epoch_index,y_true,y_pred,p_W,p_N1,p_N2,p_N3,p_REM
```

ID唯一、覆盖指定完整样本、真值一致，标签0–4；概率有限/非负/和约为1。重复/缺失/错标签/异常概率必须报错。边界改变样本时交中心样本清单，对照使用相同集合。B官方evaluate.py v1在[固定交付](https://github.com/Zptt124/EEG-EOG-sleep-staging/blob/6e7df9978c48c84bbef4d2f7e9d66e9ccd93b923/src/evaluation/evaluate.py)中，尚未因文档同步自动合入；main的`scripts/evaluate.py`仍为A临时版，不能当B官方版。

指标：Macro-F1、各类precision/recall/F1/support、N1三指标、固定类别混淆矩阵（行真列预测）、N1→W/N2/REM错向、REM表现、按人结果与同人配对差。速度/显存/参数/更新数记录设备，不能用不同GPU速度直接比较方法效率。

每run六件套：`README.md, config.yaml, history.csv, best.ckpt, metrics.json, predictions_val.csv`。另记训练/无标签名单、标准化、代码环境、权重SHA、特征版本、教师/适配模型。纯概率融合保留源run与配方，无需伪造权重。未完成/失败写最后成功步骤，不编成绩。大权重/特征在团队存储，仅向Git提交小文件与索引，不删除冻结缓存。

本轮不启动HMC/ISRUC，不实际切换62人CV，不将更多名单、五段窗口、多轮自训练或新架构扩展成核心任务。
