# B 复评：C 第四周四格 12 个 run

复评对象：PR #25（`feat/c-week4-fourcell`）、Release `c-fourcell-w4-v01-20261119`。
脚本：[scripts/38_b_w4_c_reeval.py](../../scripts/38_b_w4_c_reeval.py)。结果在 [c_reeval/](c_reeval/)。

设计（C）：D 第三周同一 backbone seed 的 step 0（随机初始化）与 30k EMA（预训练），EEG+EOG、1 秒 std、t=1；读出头 linear 或 LFT；5 人预算（label10）内按人五折选轮后全名单重训；head seed 0/1/2。12 个 run 都在同一批 8 名开发受试者的 21,186 段上评分，测试集没有使用。

## 结论

1. **C 交付的数字全部复现。** 12 个 run 都通过了下面这些核对：
   - 开发集参考核对、y_pred 等于概率 argmax、预测和 OOF 文件的 SHA256。
   - OOF 只含 5 名训练者。
   - 原始 Macro-F1、N1 F1、N1 AP，选中轮的 OOF 分数，B 独立重选的 α 和 α 调整后的指标，与 C 的差都不超过 6e-17。
   - C 报的三个配对差，B 重算的点估计与 C 完全相同。B 的 bootstrap 用 1000 次、种子 0，C 用 2000 次，两边区间几乎一样。
2. **预训练提高 Macro-F1，这一点在两种读出头下都稳定。** linear +3.2 个百分点 [+2.3, +4.3]，LFT +3.3 [+2.1, +4.3]，三个 head seed 方向都一致。
3. **N1 上，预训练的收益只在 linear 头上成立。** C 的汇总只报了 Macro-F1 和 N1 F1 的配对差，没有报协议的主指标 N1 AP，也没有报 α 调整后的配对差。B 补上了：
   - linear：预训练让 N1 AP 提高 +0.050 [+0.023, +0.087]，α 调整后的 N1 F1 也提高 +0.038 [+0.019, +0.069]，排序和门槛校正后的结果方向一致。
   - LFT：预训练对 N1 AP 没有影响（−0.004 [−0.036, +0.030]），α 调整后的 N1 F1 也没有变化（+0.004 [−0.008, +0.022]）。LFT 原始 N1 F1 的 +0.035（区间跨 0）主要来自判定门槛的位置。
4. **预训练下，LFT 的 N1 排序不如 linear。** N1 AP −0.049 [−0.092, −0.014]，α 调整后的 N1 F1 −0.029 [−0.049, −0.001]，两个区间都不含 0。原始 N1 F1 +0.075 [−0.011, +0.129] 和原始 Macro-F1 +0.007 [−0.011, +0.021] 的区间都跨 0。按 C 协议的判读表，这属于「原始 N1 F1 上升、N1 AP 下降」，指向判定门槛，而不是 LFT 学到了更好的 N1 表征。

**限制**：
- 只有一个 backbone seed，三个 head seed 共用同一个预训练主干，区间只反映受试者抽样。
- 开发集 8 人在各周反复使用。
- α 是按 OOF 的 N1 F1 选的，调整后的 Macro-F1 一般会低于原始值，所以只作为参考，不作为主指标。

| 读出头 × 主干 | Macro-F1 | N1 AP | N1 F1 原始 | N1 F1 α 调整后 | α 调整后 Macro-F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| linear × 随机初始化 | 0.670 | 0.270 | 0.162 | 0.348 | 0.649 |
| linear × 预训练 | 0.702 | 0.321 | 0.254 | 0.389 | 0.685 |

Macro-F1 均值与 C 报的一致：linear 66.98% / 70.18%，LFT 67.60% / 70.83%。逐 run 的值见 [metrics.csv](c_reeval/metrics.csv)。

## 配对差

三个 seed 的预测合并后，按 8 名开发受试者成对重采样 1000 次，给出 95% 区间。N1 AP 不受 α 影响，原始和调整后相同。

## 核对范围

- C 没有交逐轮的 OOF 曲线，所以 E* 本身无法独立重选。B 只核对了选中轮的 OOF Macro-F1 和 N1 F1 与 C 的 `training_side_summary.json` 一致。
- LFT 的训练过程（五折、全名单重训）B 没有重跑，只复评 C 交付的预测和 OOF。C 另交了独立核验脚本 `experiment3/week4/scripts/verify_fourcell.py`。
