# 1_全组共用(给 B、C、D)

本文件夹 4 个文件是全组公共依据,各实验都必须按这里的规则工作。

| 文件 | 用途 |
|------|------|
| `split_subjects.csv` | **划分文件(交接点①,全组唯一依据)**。每行一名受试者:`subject_id, record_ids, split, seed`。78 人 → train 54 / val 8 / test 16,按年龄分层,种子 42。同一受试者的全部夜晚整体归入同一集合 |
| `dataset_manifest.csv` | 数据清单:每行一晚(`record_id, subject_id, night, psg_file, hyp_file`),subject_id = 文件名前 5 位,night = 第 6 位 |
| `preprocess.yaml` | 预处理规则定稿:通道(Fpz-Cz / EOG horizontal)、100 Hz、30s 段、截取窗口、标签映射、归一化规则、sample_id 定义 |
| `data_checks.md` | 数据检查记录:下载完整性(sha256 全过)、对齐的定量验证、类别分布、以及三个数据坑的完整说明 |

## 各成员怎么用

- **B**:读 split 抽 25% 标签名单(按人抽,嵌套在 100% 名单里);用 evaluate.py 的接口规范写官方评估脚本
- **C**:按 split 的 train/val/test 对 EEG 提 EEGDM 特征(特征只对 train/val/test 各自的受试者算)
- **D**:按 split 对齐、融合、统计(只看 val)
