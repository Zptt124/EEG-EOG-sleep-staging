# 2_预处理数据与脚本(给 B、C)

交接点③:预处理好的数据 + 小 CNN 训练脚本。

## data/processed/(153 个 npz + processed_stats.csv,4.4GB)

**目录名与脚本默认路径一致**:把整个 `2_预处理数据与脚本_给B和C/` 文件夹拷到本地后,
`scripts/05_train_cnn.py` 等脚本开箱即用(脚本按 `<本文件夹>/data/processed/` 找数据)。

每个 `<record_id>.npz` 对应一晚,内含三个数组:

| 数组 | 形状 / 类型 | 说明 |
|------|------------|------|
| `signal` | (n_epochs, 2, 3000) float32 | 30s 段信号,**单位 µV**;第 0 通道 = EEG Fpz-Cz,第 1 通道 = EOG horizontal;只含截取窗口内、剔除 M/? 后的段 |
| `labels` | (n_epochs,) int8 | 0=W 1=N1 2=N2 3=N3 4=REM |
| `epoch_index` | (n_epochs,) int32 | 30s 网格序号 k(0..2879),**sample_id = `<record_id>_<k:04d>`**,全组对齐靠它 |

另附 `processed_stats.csv`:每晚保留段数、各类计数、剔除数、截取窗口。

读取方式:`np.load(path)` 即可(`signal[:, 0]` 是 EEG,`signal[:, 1]` 是 EOG)。
**注意:归一化(z-score)没有做进 npz**——按规则,均值/方差由使用方只用训练集计算(训练脚本里就是这么做的,见下)。

## scripts/(A 的全部脚本,可直接复用)

| 脚本 | 谁会用 | 用途 |
|------|--------|------|
| `05_train_cnn.py` | **B** | 小 CNN 训练。`--channel eeg/eog` 选通道;改 25% 标签只需在加载处筛 train 受试者。归一化统计量只用训练集算、最佳权重按 val Macro-F1 选,均已实现 |
| `common.py` / `metrics.py` | B(被 05 引用) | 公共常量(sample_id、标签映射)与指标计算 |
| `evaluate.py` | B(参考)、全组 | **临时版**评估脚本。B 写官方版时可对照接口与校验逻辑 |
| `04_preprocess.py` | 想复现/扩展预处理的人 | `--full` 全量重跑;`--missing` 补跑缺失;坑 1/2/3 的处理都在里面 |
| `download_data.py` | 需要原始 EDF 的人 | 走 PhysioNet 公开 S3 桶(国内快 ~600 倍),逐文件 sha256 校验 |
| `01/02/03_*.py` | 复现清单/划分/mne 检查 | 划分文件可由 `02_make_split.py --seed 42` 复现 |

运行环境:`D:\python\python.exe`(3.13,torch 2.13.0+cu126,mne 1.13),或自建环境 `pip install torch mne pandas scikit-learn pyyaml matplotlib xlrd`。
